# Dataset Creation

The recommended workflow is to use the `tempdata` CLI orchestrator, which builds the canonical cached datasets and the training feature table.

## Recommended (CLI)

```bash
tempdata data --station KLGA --start 2020-01-01 --end 2024-12-31 --timezone America/New_York
```

This writes (by default under `data/`; override via `--data-dir`):

- Clean hourly truth: `clean/hourly_obs/<station>/*.parquet`
- Daily truth: `clean/daily_tmax/<station>.parquet`
- Forecasts: `raw/daily_tmax_forecast/<station>/historical.parquet`
- Training feature table: `features/train_daily_tmax/<station>.parquet`

## Legacy / programmatic

Older script wrappers still exist under `scripts/legacy/` for reference, but are no longer the primary interface.

Feature generation is also available programmatically via `tempdata.features.build_train_daily_tmax`.
